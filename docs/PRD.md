# Hidden Gem - 맛집 리뷰 서비스 PRD

## 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| **이름** | Hidden Gem |
| **한 줄 설명** | 매일 반복되는 점심 메뉴 고민을 해결해주는 직장인 맛집 리뷰 서비스 |
| **유형** | 학습용 토이 프로젝트 (포트폴리오 겸용) |
| **난이도/규모** | 1인 개발, 소규모 |

## 2. 사용자 시나리오

| 항목 | 내용 |
| --- | --- |
| **누가** | 회사/사무실 근처에서 일하는 직장인 (1인 사용자 중심) |
| **언제** | 점심시간이 다가오는 시점 (오전 11시~12시경, "슬슬 뭐 먹지" 하는 순간) |
| **왜** | 매일 반복되는 점심 메뉴 결정 피로를 줄이고, 회사 근처 숨은 맛집을 빠르게 찾기 위해 |

### 대표 시나리오
>
> 직장인 A는 오전 11시 반쯤 되면 "오늘 뭐 먹지"라는 고민이 시작된다. 매번 가던 곳만 가기는 지겹고, 그렇다고 검색하면 광고성 리뷰만 잔뜩 나와서 믿음이 안 간다. Hidden Gem을 열어 회사 근처 숨은 맛집을 빠르게 확인하고, 오늘의 점심 메뉴를 5분 안에 결정한다.

## 3. 핵심 기능 목록

| 구분 | 기능 | 설명 |
| --- | --- | --- |
| 필수 | 맛집 검색 | 카카오 로컬 API 기반 키워드 + 카테고리 검색 |
| 필수 | 구글 리뷰 조회 | 평점/리뷰 개수/리뷰 내용을 모달로 확인 |
| 필수 | AI 리뷰 분석 | 감정 분류(긍정/보통/부정)·핵심 키워드·한 줄 요약 자동 생성 |
| 필수 | 로그인/회원가입 | 이메일/비밀번호 기반 계정 |
| 필수 | 맛집 주머니(북마크) | 담기/취소, 담은 가게 목록 조회 |
| 선택 | 인기 맛집 랭킹 | 전체 이용자가 담은 횟수 기준 TOP 5 |
| 선택 | 나를 위한 추천 | 내가 자주 담은 카테고리 기반 추천 |
| 선택 | 오늘의 추천 | 담긴 횟수에 비례한 가중치 랜덤 추천 |
| 선택 | 방문 후기 | 담은 가게에 만족/불만족 + 한줄평 남기기, 전체 이용자 후기를 홈에 모아 표시 |

※ 초기 구상이었던 영업시간 필터, 별점+사진 기반 리뷰 등록은 이번 범위에서 제외됐다 — 리뷰는 직접 등록 대신 구글 리뷰 조회(+AI 분석)와 만족/불만족 방문 후기로 대체됐고, 대신 인기 랭킹·개인화 추천처럼 처음에 없던 기능이 추가됐다.

## 6. 상세 기능 명세

### 6.1 맛집 검색

- 카카오 로컬(Local) API로 키워드 + 카테고리(한식/중식/일식/양식/카페, 단일 선택) 검색
- 키워드 없이 카테고리만 선택하면 현재 위치(권한 거부 시 강남역 좌표로 대체) 주변을 검색
- 비로그인 상태에서도 조회 가능

### 6.2 구글 리뷰 조회

- 검색 결과/맛집 주머니 카드에서 평점·리뷰 개수·리뷰 내용·구글맵 링크를 모달로 확인
- 가게 이름 + 좌표로 반경 150m 이내 구글 장소를 찾아 매칭(직접 리뷰를 등록하는 기능은 없음)
- 리뷰가 있으면 감정 분류(긍정/보통/부정)·핵심 키워드·한 줄 요약을 AI로 자동 분석해 함께 표시

### 6.3 로그인/회원가입

- 이메일/비밀번호 기반 계정 생성 및 로그인
- 로그인하지 않아도 검색, 구글 리뷰 조회 등 조회 기능은 그대로 이용 가능

### 6.4 맛집 주머니(북마크)

- 검색 결과 카드의 "담기" 버튼으로 저장/취소 토글
- **로그인 필요**
- 맛집 주머니 화면에서 담은 목록 조회·삭제

### 6.5 방문 후기

- 맛집 주머니에서 담은 가게에 만족/불만족 + 한 줄 후기 작성
- **로그인 필요**
- 작성한 후기는 전체 이용자의 최근 후기와 함께 홈 화면에 최신순으로 모여 보인다

### 6.6 인기 맛집 / 나를 위한 추천 / 오늘의 추천

- **인기 맛집**: 전체 이용자가 담은 횟수를 합산해 TOP 5를 홈에 노출(로그인 불필요)
- **나를 위한 추천**: 내가 자주 담은 카테고리를 기준으로 다른 가게를 추천(로그인 + 담은 가게 필요)
- **오늘의 추천**: 담긴 횟수에 비례한 가중치 랜덤으로 1곳을 추천, "다시 뽑기"로 재추천(로그인 불필요)
